# Getting Started

A step-by-step guide to this repo, in the order you'll use it during Session 5.

## 1. Before class

Read [`GLOSSARY.md`](GLOSSARY.md) — required pre-session reading covering all four layers.

## 2. Understand why this session exists

Read the [`README.md`](README.md) overview if you haven't already.

## 3. Learn the four-layer framework

Read [`docs/four-layers.md`](docs/four-layers.md) — defines Biology, Workflow, Execution, and Evidence layers in depth.

## 4. Review the 13 misconceptions

Read [`docs/misconceptions.md`](docs/misconceptions.md) — the specific before/after corrections this session addresses.

## 5. Examine the fragments

Open [`fragment/excerpt.nf`](fragment/excerpt.nf) and [`fragment/README.md`](fragment/README.md) — two real excerpts from Sessions 1–2 pipelines, for reading only.

## 6. Check the synthetic data

Look at:
- [`minimal-workflow/data/microbiome_samplesheet.csv`](minimal-workflow/data/microbiome_samplesheet.csv)
- [`minimal-workflow/data/microbiome_metadata.tsv`](minimal-workflow/data/microbiome_metadata.tsv)
- [`minimal-workflow/data/cancer_samplesheet.csv`](minimal-workflow/data/cancer_samplesheet.csv)

## 7. Follow the class walkthrough

Open [`EXERCISE.md`](EXERCISE.md) — the full step-by-step class exercise, including running [`minimal-workflow/main.nf`](minimal-workflow/main.nf).

## 8. Self-check before Session 6

Go through [`ENTRY_GATE.md`](ENTRY_GATE.md) — confirm you can do all 7 items before Session 6.
